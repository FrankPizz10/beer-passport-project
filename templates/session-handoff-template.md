# Session Handoff Template

Fill this in at the end of a working session so the next agent (or Frank) can pick up exactly where you left off.

## Objective worked on

What this session set out to do.

## Changes actually made

What really changed, not what was planned. Only what is committed or pushed counts.

## Repositories, branches, and commits involved

Repository, branch name, and commit SHAs or pull request links for each change.

## Tests and results

Exactly which tests passed, failed, or were not run. Include commands and output references.

## Decisions made

Any decision taken during the session, with rationale. Durable ones also go in `decisions/`.

## Outstanding issues and risks

What is unfinished, blocked, or risky. Include anything discovered that was not in scope.

## Next recommended action

The single most useful next step, and what it unblocks.
