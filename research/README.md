# research/

Findings from external research: data sources, licensing, hosting options, third-party services. Each record stands on its own so a future agent can re-verify it.

## Convention

- One Markdown file per research topic, named with a short slug (e.g., `image-licensing.md`, `hosting-cost-comparison.md`).
- Each record includes: date researched, question investigated, sources consulted (with URLs), key findings, limitations of the research, licensing or cost implications, and a recommendation.
- Research is not a decision. A recommendation here becomes a decision only when recorded in [../TECHNICAL_DECISIONS.md](../TECHNICAL_DECISIONS.md) or [decisions/](../decisions/).
- Re-verify before acting: licenses, prices, and API terms change. Note the date prominently.
