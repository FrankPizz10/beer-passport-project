# decisions/

Durable architectural and product decisions that deserve their own records. The short list of accepted decisions lives in [../TECHNICAL_DECISIONS.md](../TECHNICAL_DECISIONS.md); this folder holds the full write-ups.

## Convention

- One Markdown file per decision, named `NNN-short-slug.md` (e.g., `001-hosting-choice.md`).
- Each record includes: date, status (accepted / proposed / superseded), context, options considered, decision, rationale, consequences and affected repositories, and source or evidence.
- A decision graduates here when it is durable (affects architecture, data, API contracts, or product direction) and made (not merely proposed).
- Proposals under discussion stay in [../ROADMAP.md](../ROADMAP.md) under "Decisions awaiting approval" until they are accepted.
